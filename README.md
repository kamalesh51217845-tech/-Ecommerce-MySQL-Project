# E-Commerce MySQL Database Project

## Project Overview
A relational database project for an e-commerce application, built using MySQL.

## Technologies Used
- MySQL
- MySQL Workbench
- SQL

## Database Tables
1. Customers
2. Addresses
3. Categories
4. Brands
5. Products
6. Product_Images
7. Reviews
8. Cart
9. Cart_Items
10. Orders
11. Order_Items
12. Payments
13. Shipping
14. Coupons
15. Inventory

## Project Files
- `ecommerce_50_each (3).sql` — Sample data for the database tables.
- `ecommerce_sql_questions_answers (1).sql` — SQL practice questions and answers.

## Concepts Practiced
- Primary keys and foreign keys
- SELECT, WHERE, and ORDER BY
- Aggregate functions
- JOIN queries
- GROUP BY and subqueries
